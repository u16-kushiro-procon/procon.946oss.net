第 14 回 U-16 プログラミングコンテスト釧路大会の当日は，下記スケジュールで行います。
参加者の皆様は，13:00 までに会場の Digital Station デジラポにお集まりいただきますよう，よろしくお願いいたします。

なお，応募状況によっては，下記内容に変更が生じる場合がありますので，あらかじめご了承ください．

| 時間        | 内容              |
| ----------- | ----------------- |
| 13:00~13:30 | 開会式            |
| 13:30~15:30 | 競技部門(予選)    |
| 15:30~15:40 | 自由部門 作品紹介 |
| 15:40~16:40 | 競技部門(決勝戦)  |
| 16:40~17:00 | 閉会式            |

※自由部門は，会場内に作品を常時展示いたします．
